## Banking Analytics Dashboard

### Overview

Developed an interactive Banking Analytics Dashboard to analyze customer relationships, loans, deposits, business lending, and banking performance indicators.

### Business Problem

Financial institutions require centralized visibility into lending, deposits, customer segments, and profitability metrics.

### Tools Used

- Power BI
- Power Query
- DAX
- Excel

### Dashboard Features

- Loan Analysis
- Deposit Analysis
- Banking Summary
- Customer Segmentation
- Occupation Analysis
- Nationality Analysis
- Gender Analysis

### KPIs

- Total Clients: 365
- Total Loan: 513.76M
- Total Deposit: 409.15M
- Business Lending: 304.03M
- Savings Accounts: 77.52M
- Checking Accounts: 106.65M

### Key Insights

- Business Lending contributes approximately 59% of the total loan portfolio.
- Deposits are heavily driven by savings accounts.
- Loan portfolio exceeds deposits indicating aggressive lending.
- Male customers hold higher loan exposure than female customers.
